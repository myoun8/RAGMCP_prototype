# BT5 USANS - Ultra Small Angle Neutron Scattering

A perfect crystal diffractometer (PCD) for ultra-high resolution small-angle neutron scattering (USANS) measurements has been in operation at the thermal neutron beam port, BT-5 since 2002. The PCD increases the maximum size of features accessible with the NCNR's 30-m long, pinhole collimation SANS instruments by nearly two orders of magnitude, from ~10² nm to 10⁴ nm.

## Specifications/Capabilities

| Parameter | Value |
| :--- | :--- |
| **Q-range** | 0.0003 nm⁻¹ to ~0.1 nm⁻¹ |
| **Size Regime** | 0.1 μm to 20 μm |
| **Source** | Beam Tube (BT-5) |
| **Monochromator** | Pyrolytic Graphite Premonochromator Followed by a Triple-Bounce Si(220) Monochromator |
| **Wavelength** | 2.4 Å and 6% Δλ/λ |
| **Flux at Sample** | <17,000 neutrons-cm⁻²-s⁻¹ |
| **Sample Size** | Up to 5 cm high x 5 cm wide x 10 mm thick |
| **Analyzer** | Triple-Bounce Si(220) |
